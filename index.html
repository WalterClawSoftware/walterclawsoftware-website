Focused desktop tools

Desktop tools for creators and small teams.

Walter Claw Software LLC builds focused tools for creators and small teams doing messy real-world work. Current apps are free downloads through the official stores, including Simple Voice Reader for iPhone, iPad, Mac, and Windows. Each app does one practical job: fetch a YouTube transcript, clean transcript text, read long text aloud, package a bug report, check a YouTube banner, or export app icons.

Text to speech

Simple Voice Reader

iPhone + iPad + Mac + Windows

Use it for: listening to long text, articles, drafts, PDFs, RTF files, and plain text files instead of staring at the screen. Mac and Windows also export spoken audio.

Free for iPhone, iPad, Mac, and Windows. Mac and Windows include local Kokoro voices; the current mobile release uses installed Apple voices.
